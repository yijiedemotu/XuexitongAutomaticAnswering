# 学习通自动答题助手（浏览器扩展）

这是独立的 Chrome/Edge Manifest V3 扩展版本，不需要安装 Tampermonkey。

## 安装

1. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`）。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本文件夹 `浏览器扩展`。
5. 安装后刷新已打开的学习通页面。

## 配置

在学习通作业页面打开浮动工具的“答题设置”，选择豆包或 DeepSeek、选择模型，填写对应服务商的 API Key，点击“测试连接”后保存。设置和 API Key 使用扩展本机存储，不写入脚本文件。

豆包支持列表模型 ID，也支持在自定义模型栏填入火山方舟接入点 ID。扩展只向所选 AI 服务商发起请求。

“跳过已经作答的题目”默认开启：选择题和判断题根据页面选中标记/答案状态判断；填空题、简答题、材料题和论述题检查编辑器内容，填空题需要所有空都有内容才会跳过。可在答题设置中关闭。

每道新题都会调用当前选择的 AI 模型；缓存仅在当前页面会话的内存中，用于避免重复请求相同题目，不是预先存在的本地题库，也不会跨页面刷新保存。单选、多选和判断题会优先读取页面实际显示的选项字母，并要求模型返回对应字母；页面标签缺失或重复时，才按可见选项的屏幕显示顺序补上 A、B、C、D 等标签。作答时会触发页面自己的选项点击与暂存逻辑，并回读隐藏域确认答案已绑定；主观题写入 UEditor 后会主动调用页面保存流程。若答案无法对应页面选项，会用同一套标签再询问一次。仍无法匹配时会跳过该题、标红，并在进度面板列出题号供人工检查。页面暂时识别不到题目时会等待约 1.4 秒重扫；仍识别不到会提示检查是否已打开具体答题页，且不会发起 AI 请求。
