# 超星学习通自动答题助手

自动识别超星学习通（`chaoxing.com` / `xuexitong.com`）作业页面的题目，调用 AI 生成答案，并**直接按页面自身的规则把答案填进选项和填空里**。

提供两种安装方式，功能一致，任选其一：

| 版本 | 目录 | 需要 Tampermonkey |
|---|---|---|
| 用户脚本（Tampermonkey） | [`超星学习通自动答题助手.user.js`](./超星学习通自动答题助手.user.js) | 是 |
| 浏览器扩展（Chrome / Edge MV3） | [`浏览器扩展/`](./浏览器扩展) | 否 |

> 仅供技术学习与研究使用。请勿用于正式考试或任何违规场景，账号风险自负。

## 为什么会有这个项目

网上流传的同类脚本大多「能运行但填不上去」——日志里显示答题成功，页面上却什么也没选中。本项目对照真实的页面源码（`mooc1.chaoxing.com/mooc-ans/mooc2/work/dowork`）定位并修复了根本原因。

### 旧版的四个致命问题

| # | 问题 | 实际情况 |
|---|---|---|
| 1 | **选项容器选择器全部失效** | 页面真实容器是 `.stem_answer`，选项是 `div.answerBg`。旧版找的 `.anwserList` / `.answerList` / `.ques_options` / `.answer` 在页面上**出现 0 次**；唯一命中的 `.workTextWrap` 是题干和选项**共用**的类，导致选项数组恒为空 |
| 2 | **选项正则写错了字符** | `/[A‑D]/` 里的「‑」是 **U+2011 非断行连字符**，不是普通连字符 `-`。实测对 `A微信小程序…` 和纯字母 `A` 都**不匹配** |
| 3 | **题型判定因此恒为「单选」** | 选项为空 → 判断题、多选题、填空题全被当成单选题处理 |
| 4 | **填空题是 UEditor 富文本** | 输入框由 `UE.getEditor()` 接管，直接给 `textarea.value` 赋值页面根本不认；简答题同理 |

### 本项目的做法

不再猜测页面的内部状态，而是**按页面自己的规则作答**：

- **识别选项**：读 `span.num_option` 的 `data` 属性——那才是页面认可的值（单选 `"A"`、判断 `"true"` / `"false"`）
- **点击作答**：调用页面原生的 `window.addChoice` / `window.addMultipleChoice`（脚本版通过 `@grant unsafeWindow`，扩展版通过 `page-bridge.js` 注入主世界）。它们会自行维护 `.check_answer` 类并写入隐藏域 `#answer<qid>`，无需伪造状态
- **填空 / 简答**：用 `UE.getEditor(id).setContent()` 写入并 `sync()`，再补发 `input` 事件触发页面的 `contentChange` 回调（否则提交时会丢答案）
- **提取题干**：从 `h3.mark_name` 克隆后剔除选项节点，避免把选项文字混进题干送给 AI
- **作答校验**：写完后**回读隐藏域**确认真的写进去了，才报告成功

## 功能

- 支持 **单选题、多选题、判断题、填空题、简答题**，题型以页面 `#answertype<qid>` 隐藏域为准
- 支持两家 AI 服务商：**豆包（火山方舟）** 与 **DeepSeek 官方 API**
- 可拖动的工具条与设置面板，设置自动保存，**API Key 只存在本机**
- 「测试连接」按钮，保存前先验证 Key 和模型是否可用
- 可指定答题范围（第 N 题到第 M 题）与顺序（正序 / 倒序 / 随机）
- 可调题目间隔，内置答案缓存（同一题不重复请求）
- 扩展版默认**跳过已经作答的题目**（可在设置中关闭）
- 进度面板实时显示题干、AI 返回、每题结果，出错会明确标红

## 安装与配置

脚本版和扩展版**首次使用都必须先填 API Key**，代码里不含任何密钥。

### 方式一：Tampermonkey 用户脚本

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开 Tampermonkey 管理面板 → **添加新脚本**
3. 把 [`超星学习通自动答题助手.user.js`](./超星学习通自动答题助手.user.js) 的全部内容粘贴进去并保存
   （或直接把该 `.user.js` 文件拖进浏览器窗口，Tampermonkey 会弹出安装页）

### 方式二：Chrome / Edge 扩展

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 开启右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本仓库的 `浏览器扩展` 文件夹
4. 安装后刷新已打开的学习通页面

### 填写 API Key

1. 进入任意学习通作业作答页，页面右上角会出现 **`开始答题`** 和 **`答题设置`** 两个按钮（可拖动移动）
2. 点击 **`答题设置`**
3. 选择 **AI 服务商**，填写对应的 **API Key**：

   | 服务商 | Key 获取地址 | 说明 |
   |---|---|---|
   | 豆包（火山方舟） | <https://console.volcengine.com/ark> | 在方舟控制台创建 API Key。模型可填官方模型 ID，也可填自己的 `ep-*` 接入点 ID |
   | DeepSeek 官方 API | <https://platform.deepseek.com> | 注意：豆包的 Key 不能用于 DeepSeek，反之亦然 |

4. 建议先点 **`测试连接`**，确认返回成功
5. 按需调整题目范围、顺序、题目间隔，点 **`保存设置`**

> API Key 通过 Tampermonkey 脚本存储 / 扩展本机存储保存在本地浏览器中，不会上传给任何第三方，也**不在代码里**。

## 使用

1. 打开学习通作业页面，等题目加载完
2. 点 **`开始答题`**，进度面板会逐题显示结果
3. 过程中可随时点 **`停止`**
4. 全部跑完后，**自己检查一遍答案**，再手动点击页面上的「保存」或「提交」

### 可选开关

脚本版 `CONFIG` 顶部有几个默认关闭的开关，需要可自行改成 `true`：

| 开关 | 作用 |
|---|---|
| `AUTO_SAVE` | 填完后自动点击页面「保存」，防止答案丢失 |
| `AUTO_SUBMIT` | 自动提交作业。**不建议开启**，容易误操作 |
| `AUTO_START` | 页面加载后自动开始答题 |

## 常见问题

**看不到按钮？**
确认已进入具体的作业作答页（URL 含 `/work/dowork`），而不是作业列表页。刷新一下页面；扩展版请确认已在 `chrome://extensions` 中启用。

**答题日志显示成功，但页面上没选中？**
本版内置了回读校验：如果隐藏域没写进去，日志会明确报「点击未生效」或「答案隐藏域仍为空」。若遇到，请提 Issue 并附上页面源码片段。

**填空题填进去了但提交后是空的？**
说明 `sync()` 没生效。脚本已在写入后补发 `input` 事件触发页面回调；如仍失败请反馈。

**AI 返回格式乱了？**
对返回做了容错：会剥离 ```json 代码块、截取首尾大括号、容忍多余换行，都不行才降级当纯文本处理。

**会不会被检测？**
只是模拟正常的点击和输入。但请自行评估风险，不要用于正式考试。
